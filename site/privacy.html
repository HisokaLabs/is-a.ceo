What is public by design

Every registered subdomain is in a public Git repository. That includes the name, the record type, the record value, and the contact details you write into your entry. Treat the registry as a public document. If you need to stay unreachable, use a role address, not a personal one.

What the site itself stores

  • Theme choice. A single localStorage key named theme, holding light or dark. Following the device stores nothing. It never leaves your browser and there is no server-side copy.
  • Nothing else. The site sets no cookies, runs no fingerprinting, keeps no session id, and opens no client-side database.

Server logs

The site is served as static files from a hosting provider. That provider keeps ordinary access logs, typically the IP address, user agent, requested path, and timestamp, on its own retention schedule. {{org_name}} does not build profiles from them and does not join them to anything else. Log retention is controlled by the host, not by this site.

DNS queries on the status page

The status page resolves every registered name from your browser using DNS-over-HTTPS. Those queries go to a public resolver operated by Cloudflare, not to this site, and the resolver sees your IP address the same way it would for any other lookup. Nothing is sent back here. The same applies to the name checker: it answers by querying public DNS, not by asking a server of ours.

Third parties

  • The hosting provider for this site and its access logs.
  • Cloudflare for the DNS-over-HTTPS lookups described above.
  • GitHub for the registry repository and the pull request process. Anything you do there is governed by GitHub's own privacy policy.

There are no other third parties. No fonts are loaded from a CDN, no scripts are served from a third-party domain.

Your rights

Because the only personal data this site touches is what you put in a public registry entry, you control it by editing that entry. Removing your entry removes the record at the next deployment; Git history keeps the earlier revision, as any public repository does.

For anything else, including a request to remove data, write to {{contact_email}}. Requests are handled by a person, not a form.

Children

The service is not directed at children and no age data is collected. A subdomain claimed by someone under the age of majority is the responsibility of their guardian.

Changes

If what is collected changes, this page changes with it. There is no mailing list to notify, so the version on this page is the version that applies.
