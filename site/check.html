Availability

Is your-name free?

Type a subdomain and find out before you open a pull request. The check runs entirely in your browser against the registry: nothing is queried, nothing is logged.

.{{zone_default}}

How the rules work

  • Taken: someone else owns it. Their file lives in the registry's {{registry_dir}}/; pick another name.
  • Reserved: infrastructure names like www, api, mail. Not available.
  • Blocked: brand and impersonation names like github, gmail. Not available.
  • Free: claim it by opening a PR with a file at {{registry_dir}}/<name>.<zone>.json.

Dotted names (_acme-challenge.app) and wildcards over a base you already claim (*.app) are also allowed. Reserved and blocked lists only apply to plain single-label names. Every label is limited to 63 characters (lowercase letters, digits and hyphens, with an optional leading underscore).

One subdomain per person per zone, so check you do not already own one there. Full rules: CONTRIBUTING.md.
